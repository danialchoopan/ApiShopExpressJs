# فروشگاه حرفه‌ای نود (دیجی کالا مینی)

یک پلتفرم کامل فروشگاهی شامل API پیشرفته، پنل مدیریت چند‌سطحی و رابط کاربری مدرن.

## امکانات کلیدی
- **مدیریت درختی دسته‌بندی‌ها:** ایجاد دسته‌بندی و زیر‌دسته‌بندی (Nested Categories).
- **محصولات پیشرفته:** پشتیبانی از چندین تصویر و ویژگی‌های فنی داینامیک (Attributes).
- **پنل مدیریت هوشمند:**
  - **مدیر کل (Admin):** دسترسی کامل به تمامی بخش‌ها از جمله مدیریت کاربران و نقش‌ها.
  - **مدیر فروش (Sales Manager):** مدیریت محصولات و سفارشات.
- **رابط کاربری کاربرپسند:** طراحی شبیه به دیجی کالا، سبد خرید هوشمند و فرآیند تسویه حساب.
- **API استاندارد:** مستندات کامل برای اتصال به اپلیکیشن‌های موبایل.

## راهنمای نصب و اجرا

۱. **نصب کتابخانه‌ها:**
   ```bash
   npm install
   ```

۲. **مقداردهی اولیه پایگاه داده (Seed):**
   ```bash
   npm run seed
   ```

۳. **اجرای سرور:**
   ```bash
   npm start
   ```
   سپس به `http://localhost:3000/shop/index.html` مراجعه کنید.

## حساب‌های کاربری پیش‌فرض
- **مدیر کل:** `admin@example.com` / `admin123`
- **مدیر فروش:** `sales@example.com` / `sales123`
- **مشتری:** `user@example.com` / `user123`
